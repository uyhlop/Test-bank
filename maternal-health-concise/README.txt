MATERNAL HEALTH — CONCISE EDITION

NETLIFY DROP
1. Extract the ZIP.
2. Open https://app.netlify.com/drop or the existing site’s Deploys page.
3. Drag the extracted maternal-health-concise folder (the folder containing
   index.html) into the deployment drop area. Do not upload an extra parent
   folder that hides index.html one level below the publish root.
4. For the existing maternalhealthexam2 site, use that site’s manual deploy
   area to update it. The general Drop page may create a separate site.

No build command, package installation, account keys, or backend is needed.
You may also open index.html directly in a normal desktop browser.

CONTENTS
131 questions: all 125 original items rewritten concisely plus 6 focused
items covering Leopold maneuvers 2–4, PPROM definition and fetal risks,
and immediate care for magnesium toxicity. 123 items cover all 25 supplied
objectives; 8 original supplemental items remain labeled separately.

ANSWER DESIGN
Stems and choices were manually shortened, retaining safety-critical
context and comparable phrasing. Correct choices are not consistently
the longest. Per-session single-answer positions are balanced (counts
across A/B/C/D differ by at most one for four-option items) and randomly
assigned; other choices and SATA options are shuffled. Answer keys and
option explanations stay linked by stable identifiers, not by letter or
answer length. Orders persist when resuming a session.

FEATURES
Full exam, 20-question adaptive sessions, immediate rationales, SATA,
missed-item review, objective analytics, keyboard navigation, saved local
progress, and progress export/import are retained. SATA is exact-match:
select every correct option and no incorrect options for a correct item.
Correct selections use green gradients; incorrect selections use red.

PROGRESS
This edition has a separate browser storage key because item wording
changed and six items were added. Earlier-site backups are not imported
as scores for this revision. Use this edition’s Export progress command
for backups. Opening a new domain or a different local path may use a
separate browser storage area. No personal answers are sent to a server.
