CARDIAC & HEMATOLOGY — OFFLINE NURSING PRACTICE

1. Extract/unzip the entire ZIP.
2. Open index.html in Chrome, Edge, Firefox, or Safari.
3. Choose all categories or a single category, then Start practice.
4. Select an answer (or all correct answers for select-all items).
5. Press Check answer for immediate grading and the rationale.

Includes 42 questions covering every clue in the source game, 7 select-all
items, optional shuffled question order, category scores, answer review,
missed-question retry, and printing from the results screen.

No installation, server, account, or internet is needed to take the exam.
Source/reference links need internet. There are no external fonts, scripts,
trackers, or runtime dependencies.

Each item earns 1 point. Select-all questions require every correct choice
and no incorrect choices. There is no partial credit. Feedback appears
after Check answer, and a checked answer is locked for that attempt.

Progress saves in browser local storage when permitted. Resume with the
same browser and HTML file location. Private browsing, clearing browser
data, or moving the HTML file may erase or prevent saved progress. Only
one attempt is retained. Starting a new practice or retrying missed items
replaces that attempt. Print your results first if you want a copy.

Source: https://jeopardylabs.com/play/cardiac-and-hematology-3
Accessed: October 13, 2026. One practice question per game clue.
Original clues are available within the exam after answering each item.
Scenarios, distractors, and rationales are newly written adaptations.

Clinical corrections/qualifications are identified in question feedback.
These include heart failure weight thresholds, DASH dairy choices,
pericarditis ECG findings, AF embolic complications, troponin interpretation,
PCI timing, and modern individualized use of therapies remembered as MONA.

Independent ATI-style study material, not an official ATI product and not
affiliated with or endorsed by ATI. Scores are not standardized exam
predictions. This is educational practice, not a substitute for clinical
protocols, current guidelines, or individualized medical care.
